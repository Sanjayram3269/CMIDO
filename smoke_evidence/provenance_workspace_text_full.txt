PROVENANCE CLASSES, AS RECORDED

- OBS — Observed — recorded directly from a source dataset or file.
- DER — Derived — deterministic transformation of registered inputs.
- EST — Estimated — statistical estimate computed from data.
- SCN — Scenario — generated under controlled scenario assumptions.
Classes are read from registry records only. No class is assigned here,
and no artifact is reclassified to make the inventory look complete.

FIVE DIFFERENT CONCEPTS, KEPT APART

- File integrity: whether a file's bytes still match a recorded digest. Only a digest comparison establishes this, and this dashboard performs none.
- Schema validity: whether content matches the registered column or key contract. The dashboard performs this check when it loads an artifact.
- Reproducibility: whether the same result can be regenerated from documented inputs and steps. Recorded only where a source and generation script are documented; absent elsewhere.
- Statistical significance: a property of a statistical test recorded by a research artifact. Reported only where an artifact recorded a test.
- Scientific validity: whether method, data and conclusions are sound. Nothing on this page establishes it.

Checks performed by this dashboard

What the loading pipeline actually verifies itself, and what it deliberately does not.

✓
Available
?
Provenance n/a
●
Point estimate

These checks run at snapshot build time over registered artifacts only. They are separate from the recorded checks reported above.

PERFORMED AT LOAD TIME

- File presence — every registered artifact path is checked against the repository when the snapshot is built.
- Size cap — byte size is compared against the artifact's registered safety limit before any content is read.
- Content parse — registered CSV, JSON and text content is parsed under the artifact's loading policy.
- Column contract — expected columns are compared against the parsed table; a mismatch is recorded as invalid, never silently dropped.
- Policy enforcement — artifacts registered as blocked are refused before any read is attempted.
- Existence-only disclosure — for the unregistered files listed below, this page checks whether the file is present. It reads no content.

NOT PERFORMED BY THIS DASHBOARD

- No SHA-256 digest is recomputed. Recorded fingerprints are displayed as recorded, never re-derived and never compared against current file bytes.
- No recorded gate, audit or reconciliation is redone. Their outcomes are reported as those artifacts recorded them.
- No recorded statistical test is recomputed and no p-value, interval or effect size is recalculated.
- No authorship, collection condition, software version or methodological claim is independently verified.
- No research result is recomputed, rescored or replaced anywhere on this page.
