# CMIDO

## Research Title

**An Uncertainty-Aware Machine Learning and Multi-Objective Optimization Framework for Resilient Construction Material Procurement**

CMIDO is a research-engineering repository for the controlled development and evaluation of the finalized research framework.

## Execution Pipeline

Data
→ Probabilistic Forecasting
→ Uncertainty Quantification
→ Supply/Lead-Time Risk
→ Joint Uncertainty Propagation
→ Shortage/Service Risk
→ Multi-Objective Procurement Optimization
→ Pareto Decision Layer
→ Stress/Robustness Testing
→ Decision-Level Evaluation

The canonical research specification is stored in `docs/`. All implementation must follow that canonical specification.
